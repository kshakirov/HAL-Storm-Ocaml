Здесь открытые вопросы, а не принятые инженерные решения.

| Направление | Что проверяем дальше |
|---|---|
| Позиционный Марков | Реализовать терминальность по пустой замене из ADR-0002, проверить диапазоны и остановку; #6 |
| Строка на границах окон | Экранированные кавычки и слеши, неполный образец, настоящий EOF; явно выбрать продолжение, накопление либо временные замены |
| Пробелы и конец атома | Исключать хвостовые пробелы из диапазона, сохраняя пробелы внутри строки |
| Полнота JSON Tape | Остальная вложенность, разделители, ошибки и произвольное разбиение на окна; #9 и #10 |
| Стоимость аллокаций | Отдельно измерить копирование, представления Cstruct, контекст/frame и проход правил |
| Protobuf / DRPC | Продолжение частичного поля, владение payload и внешние границы сообщения; #8 |
| Формальная модель | Согласовать nuXmv с кодом, усилить проверяемые свойства |
| Автомат приложения | Экспериментально проверить композицию примитивов в специализированный распознаватель |

Временная замена опасных последовательностей в строке ещё не принята как решение. До реализации нужно явно определить сохранение исходных байтов и допустимость мутации.

Существующую [гипотезу](hypothesis) сохраняем. Импортированные снимки `context/` — история, не описание актуального кода.
