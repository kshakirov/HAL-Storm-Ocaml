# Архитектура

[English](Architecture) · [Home](Home) · [Русская главная](Home-RU)

Сейчас это отдельные эксперименты, а не единый универсальный парсер.

| Компонент | Исходник | Что есть |
|---|---|---|
| Eio-транспорт | `bin/main.ml` | TCP 8081, явные чтения в переиспользуемый Cstruct соединения |
| HTTP-распознаватель | `lib/parser.ml`, `lib/httpRequestParser.ml` | Побайтовые переходы, абсолютные смещения, контекст между окнами |
| JSON Tape | `test/test_tape_parser.ml` | Структурный индекс, явный стек контейнеров, примеры вложенности |
| Поиск правил | `lib/markov_parser.ml` | Позиционные Cstruct-подстановки, позиция терминального правила; ADR-0002 частично реализован |
| Protobuf | `test/test_protobuf.ml` | Обработчик полей, эксперименты varint, length-delimited и fixed32 |

Сетевое окно временное. Контекст хранит смысл прочитанного префикса. Потребитель поля сам решает, сохранять ли результат. JSON намеренно сохраняет Tape вместо объектов со значениями.

Подробнее: [транспорт](Transport-and-HTTP-RU), [Tape](JSON-Structural-Tape-RU), [правила](Markov-Rule-Matcher-RU). Компиляция примитивов в автомат приложения пока остаётся [гипотезой](Research-RU).
