# HAL-Storm — Wiki

[English](Home) · [Home](Home) · [Русская главная](Home-RU)

HAL-Storm — исследовательский проект на OCaml 5: потоковые распознаватели и структурный индекс без объектного AST. HTTP, protobuf и JSON служат полигонами. Полной реализации протоколов пока нет; отсутствие аллокаций не доказано.
