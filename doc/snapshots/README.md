# Снимки состояния проекта

`current.md` всегда содержит последний подтверждённый анализ проекта.

Перед созданием нового снимка прежний `current.md` архивируется под следующим свободным последовательным номером:

```text
0001.md
0002.md
0003.md
...
```

После архивации новый анализ записывается в `current.md`. Архивные снимки не редактируются: они фиксируют состояние проекта и выводы на соответствующий момент времени.
