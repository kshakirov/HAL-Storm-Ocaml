# ⚡️ HAL-Storm (Hardware Abstraction Layer Storm) — OCaml Edition

Высокопроизводительный асинхронный HTTP/DRPC сервер на сокетах с нуля, спроектированный на нативном языке OCaml 5 без аллокаций в куче (Zero-Allocation Engine).

## 📌 Архикетурный Манифест движка
* **Чистый Нативный Мономорфизм**: Мы ушли от ограничений .NET CLR, `IsByRefLike` и ошибок компилятора F# (`FS0412`). В OCaml 5 дженерики и структуры компилируются напрямую в высокооптимизированный машинный код процессора (x86_64 / ARM64) без промежуточного IL-кода.
* **Эффекты вместо тяжелых Task**: Асинхронный транспорт строится на базе Effect Handlers (OCaml 5) и сетевого движка **Eio**. Под Linux это обеспечивает прямой доступ к `io_uring` без кучевых аллокаций, а на macOS — максимальную скорость на уровне кремния Apple Silicon.
* **Математический детерминизм**: Обработка пакетов строится по принципу НАМ (Нормальных Алгоритмов Маркова) и побайтовых автоматов Вирта — жесткие правила подстановок и переходов, компилируемые в сверхбыстрые ассемблерные таблицы переходов (Jump Tables).
* **Бэконианский прагматичный минимализм**: Никаких сторонних парсеров и перегонки байт в строки. Весь разбор потока идет по сырому окну памяти гребенкой по индексам (`Offset` + `Length`).
