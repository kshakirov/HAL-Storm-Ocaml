## 1. Контекст и текущий статус

- **Завершённые этапы (TASK-001–003):** реализована черновая логика ДКА для первой строки HTTP-запроса (`ParseMethod` → `ParseUri` → `ParseVersion`) на уровне обработки обычных строк OCaml (`String.get`).
- **Поднятый скелет:** запущен сетевой сервер на `Eio_main` + `Eio.Net.accept_fork` с обработкой ошибок сокета (`~on_error`) и клиентского соединения.
- **Инфраструктура тестов:** создан тестовый модуль `test/test_parser.ml`. Подключён запуск через `dune runtest`. Для изоляции тестов от сети задействован `Eio.Buf_read.of_string`.

## 2. Проблема и цель тикета

Предыдущая реализация парсера (`test_wirth`) работала с фиксированной строкой `string` и абсолютными индексами `idx`. Это не позволяет обрабатывать реальный сетевой поток байт `Eio.Buf_read.t`.

**Цель:** перенести логику автомата непосредственно в функцию `wirth_parser`, переведя чтение символов со строковой индексации на потоковые операции `Eio.Buf_read`.

## 3. Задачи к исполнению

- [ ] **Рефакторинг `Parser.wirth_parser` (переход на `Eio.Buf_read.t`):**
  - заменить `String.get str idx` на потоковое побайтовое чтение `Eio.Buf_read.read_char buf`;
  - использовать `Eio.Buf_read.at_end_of_input buf` для безопасного отслеживания конца потока;
  - сохранить подсчёт смещений `s.offsets` для заголовков HTTP относительно считываемого потока.
- [ ] **Перенос логики переходов из `test_wirth`:**
  - перенести валидацию метода (`check_method_3` для `GET`/`PUT`);
  - перенести переходы по пробелам `' '`, символам `\r` и `\n` (`ExpectCRLF`, `Success`, `Error`).
- [ ] **Валидация в `test/test_parser.ml`:**
  - **Valid GET:** `"GET /index.html HTTP/1.1\r\n"` → ожидаются `state = Success` и корректные смещения;
  - **Valid PUT:** `"PUT /api/v1 HTTP/1.1\r\n"`;
  - **Invalid Method:** `"POST /index.html HTTP/1.1\r\n"` → ожидается `state = Error`;
  - **Malformed CRLF:** `"GET / HTTP/1.1\n"` → ожидается `state = Error`.

## 4. Критерии приёмки

- Логика парсинга полностью находится в `wirth_parser`; функция `test_wirth` удалена или помечена как deprecated.
- Код компилируется без предупреждений; неиспользуемые переменные обработаны через `_` или удалены.
- `dune runtest` выполняется успешно и проверяет корректность разбора моковых HTTP-строк.
