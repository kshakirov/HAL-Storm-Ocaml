## Описание

- **Описание:** Математическая верификация автомата случайными свойствами.
- **Задача:** Покрыть ДКА Вирта генераторами случайных байтовых последовательностей для автоматического поиска багов (Fuzzing/PBT).
- **Спецификация инвариантов:**
  1. **Инвариант безопасности:** любой сгенерированный поток байт никогда не должен вызывать исключений или выходов за границы буфера. Только контролируемый `Success` или `Failure`.
  2. **Инвариант корректности:** если генератор собирает валидную строку вида `[Method] + ' ' + [Uri] + ' ' + [Version] + '\r\n'`, автомат обязан вернуть `Success` со строгими координатами токенов.
  3. **Инвариант устойчивости:** произвольный бинарный мусор (fuzz-input) любой длины должен стабильно приводить к `Failure` за детерминированное число шагов, равное длине буфера.
- **Целевой файл:** `test/test_hal_storm.ml`
